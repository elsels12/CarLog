# CarLog beta 0.9.54

車の維持費・燃費・点検期限を記録する PWA です。Google スプレッドシートと Apps Script で同期します。TPSync と同じ構成です。

ファイル:

- `index.html` … 画面（単体の Web アプリ）
- `calc.js` … 税額・燃費・点検期限の計算
- `sw.js` … サービスワーカー（キャッシュ名 `carlog-beta-0.9.54`）
- `manifest.json` / `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `apple-touch-icon.png`
- `Code.gs` … スプレッドシート側のスクリプト

GitHub へのアップロードと GAS のデプロイは、利用者側で行ってください。

## セットアップ

### 1. 画面を置く（GitHub Pages など）

このフォルダ一式（`index.html` `calc.js` `sw.js` `manifest.json` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` `Code.gs`）をリポジトリに置き、GitHub Pages で公開します。`index.html` と同じ階層にすべてのファイルがある状態にしてください。

### 2. スプレッドシートを作る

同じ手順は、アプリの設定にある「接続方法（詳しく）」にも小さく書いてあります。

1. [Google スプレッドシート](https://sheets.google.com) で新しいブックを作る
2. メニューの「拡張機能」→「Apps Script」
3. 最初から入っているコードをすべて消し、アプリの設定「接続方法（詳しく）」の「Code.gsをコピー」（または「コードを表示」から選択）で取り出した内容をすべて貼り付けて保存する（ディスクアイコン、または Ctrl／⌘+S。プロジェクト名は任意）。`Code.gs` はアプリと同じフォルダに置いて公開します。画面から毎回同じファイルを取得します
4. 右上の「デプロイ」→「新しいデプロイ」
5. 「種類の選択」の横の歯車（デプロイタイプを有効にする）から「ウェブアプリ」を選ぶ
6. デプロイ構成を次のようにする
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（ログインしていなくても、リンクを知っていれば開きます。「Google アカウントを持つ全員」とは別です）
7. 「デプロイ」を押す。初回は Google アカウントの許可が必要です。「このアプリは Google で確認されていません」と出たら、左下の「詳細」を開き、「（プロジェクト名）（安全ではないページ）に移動」をタップして進みます（自分で貼った Code.gs を自分のシートで使うための確認です）。許可のあと、もう一度デプロイが必要な場合があります。
8. 表示されたウェブアプリの URL（末尾が `/exec`。形は `https://script.google.com/macros/s/…/exec`）をコピーする

スクリプトは次のシートを自動で作ります。

- `記録`（1枚目）
- `車両`
- `点検間隔`（独自の点検項目も含む。削除フラグ列あり）
- `費目`（カスタム費目の定義）
- `ゴミ箱`（削除から 90 日保持）

値はすべて文字列として保存します（先頭が `=` `+` `-` `@` の値や、数字に見える値には `'` を付け、列の表示形式を `@` にします）。数式として実行されないようにするためです。

### 3. アプリに URL を入れる

1. 公開したページを開く
2. 下の「設定」を開く
3. 「Google Apps Script のウェブアプリ URL」に、コピーした URL を貼る
4. 「接続テスト」を押して、つながることを確認する
5. 問題なければ「URLを保存」または「今すぐ同期」で記録を送る

URL はアプリに最初から入っていません。自分のスクリプトの URL だけを入れてください。末尾は `/exec` である必要があります（`/dev` はテスト用です）。

オフラインでも記録できます。つながったときに設定の「今すぐ同期」を押すと、未送信の保存・削除がシートへ送られます。接続の状態（未接続・未送信・失敗）も、この連携の欄に出ます。家族や別の端末で同じデータを使うときは、同じウェブアプリ URL を設定に入れます（スプレッドシートの共有リンクではありません）。

`Code.gs` を更新したときは、「新しいデプロイ」は使わず、「デプロイ」→「デプロイを管理」→対象の鉛筆アイコン（編集）→「バージョン」で「新バージョン」を選んで「デプロイ」します。URLはそのまま使えます。コードや権限を変えたあとは、もう一度承認が必要なことがあります。

## 使い方（概要）

- **入力** … 給油・オイル・車検などを記録。費目は大きなボタンをタップして一覧から選びます（選ぶとすぐに閉じます）。給油は合計金額・リッター・単価のうち2つを入れると残りを自動計算します。油種（レギュラー・ハイオク・軽油）は任意です（自動の欄は薄く「自動」と表示。自分で直すとその値が優先）。満タン指定で燃費を出します。車検は重量税・自賠責・印紙代・整備費の内訳を書けます。
- **ホーム** … 車両チップ（タップで切り替え。最後に選んだ車両を覚えます）、よく使う記録のショートカット（給油やカスタム費目など、ワンタップで入力へ）、点検アラート、最近の記録。車両カードの走行距離は、いちばん新しい記録（主に給油）のオドメーターを参照し、出典を表示します。税金の目安は折りたたみ。月平均（当月と前2か月）・直近3回の満タン区間燃費は履歴タブ（平均燃費カードからも開けます）。左右スワイプで下のタブ（ホーム／入力／履歴／点検／設定）を移動できます。スワイプ中は画面の内容だけが横に滑り、上の CarLog と下のタブバーの枠はそのままです。下のタブの選択色（ハイライトと上の細い帯、文字色）は、指の動きに合わせて隣のタブへ連続して移動します（離すと確定先へ、戻すと元へ滑って止まります）。スライド中の画面は、止まったあとと同じ余白・幅・背景で描くため、止まった瞬間に上下や枠線の見え方がずれません（0.9.44）。アイコンは、丸みのあるハッチバックを線だけで描いたシンプルなデザインです（ホーム画面に追加済みの場合は、いったん削除して追加し直すと新しいアイコンになります）。下のタブバーは、5つのタブを左右の端から内側へ寄せ（左右14px）、高さも少し低くしました（0.9.44）。点検の編集画面で、前回交換の日付欄が隣の欄に被る表示崩れを直しました（0.9.44）。点検アラートのカードは、進捗バーと「完了」ボタン周りの余白を詰めて、1画面に多く表示できるようにしました（高さ約23%減）。点検カードやホームのアラートの上でも切り替えられます。横にスクロールする欄（車両チップが溢れているときなど）と入力欄、バナー編集ではスワイプを無視します。ショートカットの順番は、ホームでタイルを長押しして並べ替え、「完了」で終わります。種類や順番は設定の「ホームのショートカット」でも変えられます。色、線／塗り、不透明度（塗りは初期値85%、線は100%。10〜100%で変えられます）、アイコンサイズ（特大／大／中横／中／小横／小。初期は中。小は中の半分の幅と高さで中1つの位置に4つ（2×2）並び、ラベルは1行（入らなければアイコンのみ）。小横は中と同じ幅・小と同じ高さ、中横は特大と同じ幅・中と同じ高さで、アイコンの右にラベルを1行で出します。大は小横を横に2つ・縦に3つ分（特大と同じ幅、マス3つ分の高さ）で、アイコンとラベルを中央に重ねます。特大は中2つ分の幅×2段で、空いたマスは詰めて並びます）は、各ショートカットの「見た目」で項目ごとに設定できます。以前の全体サイズ指定は、各項目の初期値として引き継がれます。よければ、使い方の「ホーム画面に追加」にある手順で、ホーム画面からアプリのように開くこともできます（必須ではありません）。車両ごとに、ホーム上部へ任意のバナー画像（X のプロフィールヘッダーのような横長。端末内の IndexedDB に保存）を置けます。設定の車両編集から写真を選び、位置とズームを調整できます。スプレッドシートには送りません。
- **入力** … 記録する車は、画面右上の車両メニューで切り替えます（入力画面内のチップはありません）。交通費の内訳は高速代が初期値で、有料道路・フェリー・カーシェアなども選べます（バス・電車は出しません）。装備とカスタムは「カスタム・装備品」にまとめています。カスタム費目も選択肢に出ます。
- **点検** … オイル・プラグなどの標準項目に加え、「＋項目を追加」でタイミングベルトなど独自の点検を、名前と間隔（km / 月）で登録できます（費目とは別）。各項目の状態バッジの右にある鉛筆（編集）から間隔と前回交換を変え、「完了」で今回の交換を記録します。前回の交換記録と、給油記録などから拾った現在距離のうち早い方で「間近／超過」を出します。間隔の変更は、今見ている車両向けに保存されます。カスタム費目に付けた間隔も出ます。
- **車検の最低目安（0.9.52）** … ホームの「税金・自賠責」に、重量税＋自賠責＋印紙代（2,100円・2026年4月改定の窓口額）＋代行手数料（10,000円・ディーラー相場）を足した「整備なし」の最低ラインを表示します（2026年時点の料金）。実際は交換・修理で高くなるのが一般的です。
- **ポップアップ（0.9.51）** … すべて画面の中央に出し、横にずれないようにしました。使い方は「閉じる」を下に固定。目安の注意書きは短くし、「ホーム画面に追加」は設定ページに直接書きました。
- **車両の編集画面（0.9.50）** … 排気量は自動車税の区切り（軽自動車／1.0L以下／1.5L以下…）のドロップダウンにしました。車両重量は重量税（0.5tごと）の目安に使います。画面は1枚に収め、横にずれないようにしました（バナーは折りたたみ）。
- **履歴の全車表示（0.9.48）** … 車が2台以上のとき、ホームの車名チップの右端「全車」か、画面上の車名の選択肢「全車（履歴）」を選ぶと、履歴が全車分になります（記録ごとに車名が付き、今月・今年の合計と費目別も全車分。平均燃費は車ごとなので出しません）。ホーム・点検・入力は最後に選んだ車のままで、履歴の記録をタップするとその記録の車に切り替わります。車名を選ぶと、その車だけの表示に戻ります。
- **履歴の絞り込みタブ（0.9.48）** … 絞り込みタブ（すべて／給油／…）を押したときも、タブが画面の一番上に来たままになります。タブの列を左右にスライドすると隠れた費目が出ます。さらに、**絞り込みタブより下を左右にスライドすると、画面の位置と高さは変わらず、項目（すべて／給油／…）だけが隣に切り替わります**（端では動きません）。履歴以外のページでは、これまでどおり下タブの移動です。
- **使い方の追加（0.9.48）** … 設定の「使い方」に「金額・時期は目安です」「操作のコツ（スライド・長押しなど）」「カレンダー通知」「電気自動車（EV）・ハイブリッド」を足し、点検・履歴の説明を最新にしました。点検タブ、履歴の下、点検のポップアップにも「目安」の注意書きを入れています。
- **入力後の点検ポップアップ（0.9.46）** … 記録を保存したあと、点検の「完了」を記録したあとに、「注意」以上（距離は残り800km以内、期間は残り60日以内、超過を含む）の項目が1つでもあれば、「○○の交換が迫っています」「○○の交換時期を過ぎています」と、該当する項目をすべて一覧で出します。いちばん近いものが上です。「閉じる」は大きなボタンです。
- **ホームの見出し・履歴ボタン・見た目の編集（0.9.45）** … ホームの「点検アラート」「最近の記録」の見出しは、アクセント色を白寄りにやわらげました。「履歴を見る」は、入力後と同じく履歴タブの絞り込みタブ（すべて）が一番上に来ます。見た目の編集は、タイトルとサンプルを上に固定して設定欄だけをスクロールし、保存ボタンも下に固定しました。線の色は、アイコンと文字だけを変え、枠は塗りの色（なければ線の色）のままです。
- **前回が未記録の点検（0.9.44）** … 前回の記録がない月数つきの項目も、アプリで初めて見た日を仮の起点にして「起点＋月数」で予定を入れます（題名に「（仮）」が付きます）。点検タブで「完了」にすると、実績の日付に置き換わります。
- **点検アラートの色（0.9.44）** … 赤は点検タブに近い色（#ff7a5c）、オレンジ・黄・緑は同じくすみ・透け感の色で、すべてテーマを変えても同じ色です。残りに応じて、赤（超過・0）→オレンジ→黄→緑（距離1,200 km／期間80日）へなめらかに変わり、バー、文字、バッジ、完了ボタンが同じ色になります。
- **ショートカット編集の見直し（0.9.44）** … 塗りのスタイルで、枠は塗りの色のままにし、線の色はアイコンと文字だけに使います。サンプル（プレビュー）は、編集画面の一番上に固定して、下へスクロールしても見えるようにしました。
- **ホームの「履歴を見る」（0.9.44）** … 保存後と同じく、履歴タブの「すべて」などの絞り込みタブが一番上に来る位置で開きます。見出し「点検アラート」「最近の記録」は、テーマに左右されない落ち着いた色にしました。
- **上のバー（0.9.44）** … CarLog・バージョン・BETA の色は、タブを切り替えても変わりません。
- **ショートカットの塗りの色と線の色（0.9.44）** … 費目の見た目の編集で、塗りの色（タイルの背景）と線の色（アイコン・文字・枠）を別々に選べます。線の色が「自動」のときは、塗りでは読みやすい色、線では塗りの色になります。シートには「色」の列に「#塗り/#線」の形で入れるので、Code.gs の変更は要りません。
- **入力後の移動（0.9.44）** … 記録を保存したとき、点検の「完了」を記録したときは、履歴タブの「すべて」などの絞り込みタブ（全部の履歴の先頭）が画面の一番上に来るように移ります。
- **バッジの5段階と出し始め（0.9.44）** … 点検カードのバッジは、残りに合わせて 余裕（緑）/ 確認 / 注意 / 警告（オレンジ）/ 超過（赤）になります。ホームの点検アラートには「確認」から出ます（余裕は出しません）。距離は 余裕 1,200 km より多い / 確認 1,200〜800 / 注意 800〜500 / 警告 500〜1 / 超過 0 km 以下、期間は 余裕 80日より多い / 確認 80〜60 / 注意 60〜30 / 警告 30〜1 / 超過 0日以下です。色はこの段階に合わせてなめらかに変わり、バー・バッジ・完了ボタンが同じ色になります。間隔が短い項目では、間隔の半分までに縮めます。
- **EV（0.9.44）** … 車の燃料で「EV」を選ぶと、エンジンオイル・オイルフィルター・プラグ・エアフィルターが点検から外れます。給油記録は「充電量（kWh）」「円/kWh」「電費（km/kWh）」の表示になります（記録の形は給油と同じで、満タンは満充電の意味です）。ハイブリッドとPHEVはエンジンがあるので、いままでどおりオイル系も点検します。
- **履歴** … いま選んでいる車の今月・今年（1月1日から今日まで）の合計と通算の平均燃費（タップで詳細）が一番上に出ます。その下に燃費の詳細と、今年の費目別内訳・合計、フィルタと記録一覧が続きます。
- **設定** … カスタム費目の追加・編集・削除（名前、アイコン、色、内訳、任意の点検間隔）、組み込み費目を入力から外す（記録は残します）、テーマ（ガラス／ガラス・ライト／ニューモ／ニューモ・ダーク／ネオン。初期はガラス。この端末に保存）、複数台の車両（編集画面でホーム用バナーを設定）、走行距離の出典確認（手動入力は記録がないときだけ）、CSV の書き出し（選択中の車／全車、今年／全期間、出す項目と費目を選べます。UTF-8 BOM、数式インジェクション対策、ファイル名は `carlog_車名_YYYYMMDD.csv`）／読み込み、JSON の完全バックアップと復元（統合または置き換え）、連携中シートからの復元、連携 URL（設定の「接続方法（詳しく）」に手順あり）。費目を削除しても、その記録は保存されていた名前のまま残ります。

各カードは暗い背景のまま、セクションごとに左の色帯とごく薄い地色を変えて区別しやすくしています（コントラストは確保しています）。 下のタブ（ホーム／入力／履歴／点検／設定）も同じ系統の色で分け、選んでいるタブは色付きの背景で示します。ショートカットとタブのアイコンは、同じ太さの線でそろえたシンプルな形です。

初めて開いたときは車は入っていません。ホームの「車を登録する」から、名前・排気量・燃料・初度登録・車両重量・軽／エコ・次回車検などを登録します。最初に登録した車が選択中の車になります。設定の「デモデータを入れる」は、86 ZN6（1,998 cc、ガソリン、2012年4月、1,240 kg）向けのサンプル記録を、必要なときだけ追加します。自動では入りません。 車検は「購入後の初回車検日」を一度入れると、以後の期限を出します。新車は初度登録の3年後です。受けられる期間（期限の1か月前から、期限後も）に入ると、点検カードに「予約完了」と「完了」が出ます。「予約完了」で予約日を選び、警告の代わりに「予約済」と予約日（例：予約日 11/28（期限 12/4））が出ます。予約は完了ではないので、完了するまでホームのアラートと点検タブの印に残ります。もう一度開いて日付を直すか「予約取消」できます。「完了」で新しい期限を入れます（2年後の同じ月を目安に出します。店によって違うので車検証の日付を優先）。自賠責の期限表示も同じサイクルです。点検アラートは、受けられる1か月前の7日前から段階的に出ます（アプリを開いているとき）。

## 燃費の出し方

満タンから次の満タンまでの距離を、その間に入れた燃料（途中の非満タン給油も含む）で割ります。

- **通算平均** … すべての区間の距離合計 ÷ リットル合計（ホームのカード。直近だけではありません）
- **給油ごと** … 満タン記録のそれぞれについて、前回満タンからの区間燃費。詳細では直近3回だけ表示します
- **月平均** … その月に終わった区間の距離合計 ÷ リットル合計。詳細では当月と前2か月（計3か月）だけ表示します
- **航続距離ランキング TOP3** … 1回の給油ごとの走行距離（直前の給油記録からのオドメーター差。満タン・非満タンを混ぜません）。通算の上位3件。燃費（km/L）は、その回が満タンで満タン法の区間が計算できるときだけ表示します

## テーマ

設定の「テーマ」から、5つの見た目をすぐ切り替えられます。初期はガラスです。選んだテーマはこの端末に保存され、JSON バックアップの設定にも含まれます。本文・数字・日付・ラベルは、どのテーマでも同じ読みやすいゴシック体（Hiragino Sans / Noto Sans JP / Noto Sans CJK JP）です。数字は等幅（tabular-nums）です。外からフォントは読み込みません。

- **ガラス**（初期）… 深いインク／ネイビーを地にして、青・シアン・少しのエメラルドの光をやわらかく置きます（補色を混ぜないので濁りません）。0.9.2 より色の滲みを少し戻しています。カードは同じ半透明のフロストで、上辺の光のハイライトと枠をはっきりさせ、カード同士の間隔も少し広げています。ぼかしは固定のヘッダーとタブだけです。
- **ガラス・ライト** … 明るいパステルの青・シアン・エメラルドの光の上に、白い半透明のフロストカードを置きます（0.9.44 でカード・ショートカット・入力欄の白をさらに薄くし、ガラスに近い透け方にしました）。枠をはっきりさせ、文字は濃い色で読みやすくしています。
- **ニューモ** … 落ち着いた単色のまま、青みを抑えた中性グレーをベースにしています。影は箱の近くにとどめ、カード同士の間隔を揃え、1px の枠で各ボックスがはっきり分かれて見えるようにしています。
- **ニューモ・ダーク** … 真っ黒ではないチャコールグレーのベースに、暗い画面向けの二重の影をのせます。枠・間隔・引き締めた影はニューモと同じで、アクセントは同じ緑です。
- **ネオン** … 暗い路地のようなレンガ壁の前に、看板のようなチューブ枠をつけます。色はシアン／ホットピンク／アシッドライム／暖かい赤・アンバー。管は途切れのない一本の枠です。「最近の記録」の管は一段暗いです。ロゴも同じゴシック体で、字重と字間と発光だけ看板風にしています。見出しは発光するネオン文字です（動きはありません）。

費目の色と、ショートカットの線／塗り・不透明度は、どのテーマでも使えます。下のタブと各カードの色帯もテーマごとに合わせてあります。

## データ書き出しとバックアップ

- **CSV** … 設定の「書き出し（バックアップなど）」から書き出します。範囲は選択中の車／全車、今年（1月1日から今日まで）／全期間。出す列と費目も選べます。文字コードは UTF-8（先頭に BOM）、改行は CRLF、値は RFC 4180 に沿って引用符で囲みます。`=` `+` `-` `@` で始まる値は先頭に `'` を付け、表計算ソフトが数式として開かないようにします。ファイル名は `carlog_車名_YYYYMMDD.csv`（全車のときは `carlog_全車_YYYYMMDD.csv`）です。
- **JSON 完全バックアップ** … 車両、記録、費目とスタイル、点検項目、ショートカットなどの設定、スキーマバージョンを含めます。連携 URL は標準では入れず、必要なときだけ「連携URLも含める」をオンにします。ホームのバナー画像も標準では入れず、必要なときだけ「画像を含める」をオンにします（Base64。ファイルが大きくなります）。バナーは端末内の IndexedDB に保存し、スプレッドシートには同期しません。対応していれば共有シート（Web Share API、ファイル付き）で送り、使えなければダウンロードします。
- **復元** … JSON から「統合」（同じ ID は更新日時の新しい方を残す）か「置き換え」を選べます。置き換えは取り消せないため、確認を2回出します。形式が正しくないファイルは取り込みません。取り込んだ記録は未送信に載せ、次の同期でシートへ送られます。
- **スプレッドシート** … 連携中のシートはクラウドの控えになります。「スプレッドシートから復元」はシートの `getAll` を取り、同じように統合または置き換えできます（「今すぐ同期」でもシートの内容は端末へマージされます）。最終バックアップの日付を表示し、未連携でまだ一度もない、または30日以上経っているときは短い注意を出します。

## カレンダー通知（車検・点検）

車検の期限と、月数が決まっている点検項目（オイルなど）の期限を、Google カレンダーの専用カレンダー「CarLog」に終日予定として入れ、スマホの通知で知らせます。設定の「カレンダー通知（車検・点検）」でオンにします。

- **通知のタイミング** … 約1か月前（4週間前。Google の上限）・1週間前・前日の、いずれも朝9時
- **自動で置き換わる** … 車検日を直したり、点検項目を期限の前に「完了」にしたりすると、いまの予定を消して、次のタイミング（前回交換＋月数）の日に予定を入れ直します。車両や項目を消すと予定も消えます。オフにするときは、予定を消すかどうかを選べます
- **点検項目の日付** … 前回交換の日付＋月数です。前回交換が未設定の項目は予定を作りません。期限をすぎた項目は、新しく予定を作りません（すでにある予定は、完了するまで残ります）
- **対象外** … 距離（km）だけで決まる項目は、日付では決まらないので通知しません。月数と距離の両方がある項目（エンジンオイルなど）は、月数の日付で通知します。距離が先に来たときは、点検タブとホームで確認してください
- **自賠責** … 自賠責の期限は車検と同じサイクルなので、別の予定は作りません。予定の説明に「自賠責もあわせて確認」と書きます
- **受け取る側** … スマホの Google カレンダーアプリ、または標準カレンダーに Google アカウントを追加してください（iPhone は 設定 → カレンダー → アカウント）

使い始める手順（Code.gs を更新したあと、一度だけ）:

1. Apps Script で `Code.gs` を最新に入れ替えて保存する
2. 上のメニューの関数選択で `authorizeCalendar` を選び、「実行」を押してカレンダーの承認をする（「確認されていません」と出たら「詳細」から進む）
3. 「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」（URL はそのまま）
4. アプリの設定で「車検の期限を Google カレンダーに入れる」にチェックを入れる

予定は GAS を作った人（自分）のカレンダーに入ります。家族など別の人の端末で通知したいときは、その人が自分の GAS を作ってください。

## 金額・時期はすべて「概算・目安」です

このアプリが出す金額・日付・距離は、概算や目安です。実際の請求額や、守るべき整備時期とは違うことがあります。

- **税金・自賠責・重量税** … 公開されている税率表からの目安です（下の節）。正しい金額は、納税通知書・保険証券・車検の見積書で確認してください。
- **燃費・航続距離** … 入力した給油量と走行距離からの計算（満タン法）です。入力の抜けや、満タンの入れ方でずれます。
- **点検の時期** … 間隔（km・月）と前回の交換からの目安です。取扱説明書・整備手帳・整備工場の指示を優先してください。
- **車検の期限** … 2年ごとの目安です（新車は初回が3年後）。正しい期限は車検証の日付です。
- **走行距離** … 記録した最新の値からの目安です。メーターと違うときは、記録を直してください。

このアプリの表示を根拠にした損失や事故の責任は負えません。大事な判断は、公式の書類と整備工場で確かめてください。画面では、設定の「使い方」と、点検・履歴・ポップアップの注意書きにも同じことを書いています。

## 税額・自賠責は「目安」です

画面にも **目安** と出しています。グリーン化特例、自治体の減免、年度途中の月割、離島・沖縄の自賠責は含みません。納税通知と、国土交通省の「次回自動車重量税額照会サービス」を優先してください。

## この版の限界

- ベータ（beta 0.9.44）です。完成するまでは BETA と表示します。見た目や項目はこれから直せます。
- グリーン化特例、エコカー減税の個別判定、月割、営業用、貨物車、離島・沖縄の自賠責は未対応です。
- チームでの同時編集の競合は、新しい `updatedAt` を優先する程度です。
- 点検項目の交換記録を端末間で突き合わせる `maintenanceItemId` は、いま CSV と端末内に保存します（記録シートの列は増えていません）。カテゴリと内訳の名前でも照合します。
- アプリ自身のプッシュ通知はありません。車検はカレンダー通知（上記）、距離基準の点検はアプリを開いたときにホームと点検タブで確認します。
